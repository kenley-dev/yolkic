# 🍳 Yolkic

> *Automating high-volume shell separation for commercial kitchens and food processing.*

Welcome to the official repository for **Yolkic**, Waterloo's first-ever automated egg-cracker for high-throughput culinary operations. 

---

### ⚙️ About the Project
Designed for commercial kitchens, industrial bakeries, and food manufacturing operations that process thousands of eggs daily, Yolkic eliminates labor bottlenecks, reduces shell-contamination risks, and maximizes yield. By combining precision mechatronics with automated handling, our system **cracks the code** to industrial-scale breakfast prep.

---

### 🛠️ Tech Stack & Hardware
* **Platform:** VEX IQ Gen 2
* **Language:** C++ (VEXcode IQ)
* **Actuation:** Smart motors and precision sensors for automated egg feeding, clamping, and clean shell-separation.
